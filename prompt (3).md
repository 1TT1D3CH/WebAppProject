# 🛡️ AI Antigravity Master Prompt: SecurifyMe (Vue 3 + Vite + Tailwind CSS)

## 📌 Project Overview
Create a complete, production-ready, interactive Web Application named **"SecurifyMe"** built using **Vue 3 (Composition API / `<script setup>`)**, **Vite**, **Tailwind CSS**, and **Lucide Vue Icons**.

SecurifyMe is a comprehensive **Privacy & Security Hardening Suite** designed for everyday social media users. It goes beyond a simple checklist by providing interactive security tools, real-time exposure simulation, and gamified security training.

---

## 🛠️ Technology Stack Requirements
- **Frontend Framework:** Vue 3 (Composition API with `<script setup>`)
- **Build Tool:** Vite
- **Package Manager:** npm
- **Styling:** Tailwind CSS (configured via PostCSS)
- **State & Interactivity:** Vue Reactivity (`ref`, `reactive`, `computed`, `watch`)
- **Libraries & Icons:** `canvas-confetti`, `lucide-vue-next`
